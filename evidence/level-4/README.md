# Level 4 Evidence

This directory stores reviewed, non-secret evidence for the Level 4 pilot.

Planned artifacts:

- `wallet-interactions.json` — machine-readable, RPC-verified Testnet proofs.
- `wallet-interactions.md` — reviewer-friendly summary with Explorer links.
- `feedback-summary.md` — aggregated findings and implemented responses.
- `pilot-metrics.json` — measured onboarding and usability metrics.

Do not commit wallet secrets, participant names, email addresses, raw GPS,
private feedback, access tokens, or unredacted monitoring payloads.

Evidence must only be added after real participants complete the pilot. Empty,
mocked, duplicated, or team-invented interactions do not count.
