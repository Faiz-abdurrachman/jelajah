# JELAJAH — Economics & Revenue

## 1. Revenue Sources

| Source | Detail | Target |
|---|---|---|
| **Brand Subscription** | Basic (free), Pro (Rp 500rb/bln), Enterprise (custom) | Small - medium business |
| **Managed Campaign** | Kita design + manage hunt buat brand (Rp 5jt+) | Enterprise |
| **Dispute Fee** | 5% dari nilai hunt yang dispute | Users |
| **Featured Hunt** | Hider bayar boost biar hunt muncul di top map (Rp 20rb/hunt) | Hider |
| **Appeal Fee** | Rp 100rb per appeal | Users |
| **API Access** | Developer access untuk integrasi | Third-party |

---

## 2. Fee Distribution (Dispute)

Nilai hunt: Rp 1.000.000
Fee 5%: Rp 50.000

```
Rp 50.000 → 60% ke 3 verifikator = Rp 30.000 (Rp 10.000/orang)
         → 25% ke platform        = Rp 12.500
         → 15% ke treasury        = Rp 7.500
```

---

## 3. Verifier Economics

| Metrik | Value |
|---|---|
| Min stake | 5.000 XLM |
| Fee per dispute | ~Rp 10.000 (rata-rata dispute Rp 1jt) |
| Time per dispute | ~5 menit review |
| Potential earning | Rp 10.000 / 5 menit = Rp 120rb/jam |
| Slash penalty | 10% - 100% stake tergantung pelanggaran |

## 5. Platform Treasury

Treasury fund berasal dari:
- 15% dispute fee
- Slash stake verifikator
- Brand subscription overage

Digunakan untuk:
- Bounty program (bug report, feature request)
- Community grants
- Top-up prize pool event bulanan
- Development fund

## 7. Token?

**MVP: TIDAK ADA TOKEN.**

- Semua transaksi pakai XLM atau USDC native
- Stake verifikator dalam XLM
- Reward hunter dalam XLM/USDC
- Token bisa di-consider nanti (L6+) kalau perlu governance

Alasan gak pake token:
- Gak perlu spekulasi
- Fokus ke utility, bukan trading
- Simpel buat dijelasin ke juri
- Gak perlu whitepaper tokenomics
